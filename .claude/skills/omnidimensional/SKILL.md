# Omnidimensional Analysis Framework

Cold, systematic, no-ceiling. Escalate from flat contrast to emergent 4D pattern.
No flattery. No filler.

## Phase 0 — Raw Intake (cold shot of reality)
Strip the subject to what it actually is before any rotation.
- State it plainly. No spin, no framing — the thing itself.
- Identify its core units — the irreducible components.
- Note visible vs. assumed/hidden.
- Call out loaded framing in how it was presented; restate neutrally.
This is ground truth. Everything rests on it. **Never soften it to be palatable.**

## Phase 1 — 2D Plane (full rotation)
- **1a Contrast:** clear differences, tensions, contradictions, competing forces. Don't smooth them.
- **1b Coincidence:** what recurs or rhymes; where opposites share hidden structure; what looks different but is functionally the same.
- **1c Linear alignment:** arrange elements causally; run the mirrored version alongside; compare where they track vs. diverge.
- **1d Reversal:** run it backwards. Effect becomes cause, conclusion becomes premise. What does forward-facing obscure?
- **1e Acute angle:** the oblique view (not opposite, not mirror). Min 4 angles (0°, ~45°, ~90°, ~135°).
- **1f 360° record:** compile a flat map — max-tension points, convergence points, dead zones, surprises.

## Phase 2 — 3D Emergence (aerial + parallel)
- **2a Aerial:** view the 2D map from above. Clusters, outliers, repeating structures, center of gravity.
- **2b Parallel plane shift:** offset the subject one degree (neutral third party / competitor / different domain). Repeat at multiple offsets.
- **2c Intersection fusion:** where parallel planes cross = high-information nodes. Fuse them.
- **2d Unit explosion:** expand each fused node as its own system; run a mini Phase 1 if warranted.
- **2e 3D composite:** reassemble. Shape, load-bearing points, weak spots, surprising geometries.

## Phase 3 — 4D Planes (time + emergence)
- **3a Temporal rotation:** run the 3D structure at origin, maturity, decay/inversion. Constants = deep structure.
- **3b Fuse and repeat:** overlap past/future states. What pattern is it always trying to complete?
- **3c Emergent 4D pattern:** name it. The irreducible truth that persists across all rotations/time. 1–3 sentences. This is the answer that required all of the above.

## Output rules
| Subject | Default output |
|---|---|
| Decision / situation | Structured breakdown, clear headers |
| Idea / concept | Flowing analysis, visual map if complexity warrants |
| Data / system | Diagram-first, synthesis after |
| Personal / interpersonal | Written, plain, no jargon |
| Abstract / philosophical | Free-form prose mirroring the subject's structure |

**Always include:** the Phase 0 restatement (however uncomfortable); the 4D pattern at the end; any surprises that contradicted the obvious read.
**Never:** soften Phase 0; skip phases because it "seems simple"; resolve genuine tensions into false synthesis — if it's contradictory, say so.

## Depth calibration
Default: no ceiling, go until the pattern is visible. If speed is needed: compress each phase to its single sharpest insight per step — same structure, denser.
